## 1. 이 특강이 하려는 일

한 달 남은 수험생에게 필요한 건 새 자료가 아니라 **이미 본 내용이 한 장의 구조로 꿰어지는 경험**이다.
이론 과정은 자료를 쏟아붓지 않는다. 강마다 비유 하나로 시작해서, 그 비유가 지식의 뼈대가 되고,
뼈대에 개념이 하나씩 붙어 가는 방식으로만 진행한다. 외우라고 시키지 않는다. 구조가 이해되면 외워지는 순서로 설명한다.

기출 과정은 해설지를 읽어 주는 수업이 아니다. 답은 해설지에 있다. 이 과정은 **답이 정해지는 원리**를 가르친다.
개념 지도를 빠르게 다시 세우고, 같은 원리로 풀리는 문제를 묶어서 공업 기출과 타교과 인접 기출을 고속으로 쳐 나간다.
그래서 처음 보는 유형이 나와도 같은 원리로 풀 수 있게 만든다.

### 강의 화법 원칙 (모든 대본에 적용)

| 한다 | 하지 않는다 |
|---|---|
| 강사가 질문을 던지고 그 자리에서 함께 풀어 간다 ("자, 그럼 이건 뭘까요? 네, 응용이죠. 왜냐면…") | "잠시 멈추고 써 보세요", "외워 보세요", "이해해 보세요" 같은 과제 지시 |
| 비유 → 구조 → 개념 → 판단 기준 → 다시 비유 | 개념 이름부터 나열하는 자료 폭격 |
| 기출 지문은 강사가 직접 읽으며 어느 단어에서 답이 정해지는지 보여 준다 | 정지 화면·카운트다운·인출 대기 시간 |
| 헷갈리는 짝은 "왜 헷갈리는지"부터 짚고 갈라 준다 | 원문·쪽수·출처·검증 여부 같은 제작용 말 |
| 시험장에서 쓰는 문장 그대로 정리해 준다 | 같은 내용을 반복해 길이를 채우는 것 |

## 2. 수업 설계의 뼈대 (화면 밖에서 작동하는 설계 원리)

이 원리들은 강의 중에 이름으로 등장하지 않는다. 대본과 화면 구성 안에 녹아 있다.

### 정교화 이론 — 줌 렌즈 구조
- **개관(에피톰)**: 이론 1강 첫 장면에서 공업교육론 전체를 "기술인 한 명을 길러 내는 다섯 질문"으로 보여 준다.
  왜 기르나 → 무엇을 가르치나 → 어떻게 가르치나 → 잘 배웠나 → 현장과 어떻게 잇나.
  공식 7영역은 전부 이 다섯 질문 중 하나에 매달린다.
- **줌인/줌아웃**: 매 강은 이 지도의 한 칸에서 출발해 안으로 들어가고, 끝나면 지도로 돌아온다.
  영상에서는 카메라 이동이 아니라 **노드가 열리고 닫히는 모프**로 표현된다.
- **요약자·종합자**: 묶음이 끝날 때마다 "지금까지를 한 줄로", 강 끝에는 개념끼리의 관계를 한 장으로.
- **비유(인지적 전략자)**: 강마다 하나의 핵심 비유가 처음과 끝을 잇는다.

### 인지적 도제 — 강사의 머릿속을 보여 주기
- **모델링**: 지문을 읽을 때 화면의 커서가 강사의 시선을 따라간다. 어느 단어에서 멈추고, 무엇을 지우고, 무엇에 밑줄을 긋는지 보인다.
- **스캐폴딩과 페이딩**: 같은 원리의 문제를 연달아 풀 때, 첫 문제는 단서를 하나하나 다 짚고,
  둘째는 결정적 단서만, 셋째부터는 결론과 근거 한 줄로 끝난다. 지원이 화면에서 눈에 띄게 줄어든다.
- **명료화·반성**: 정답 뒤에 "이걸 ○○로 쓰면 왜 틀리는지"를 짧게 붙여 판단 기준을 말로 남긴다.
- **탐구**: 기출 과정 끝에는 같은 원리로 나올 수 있는 다음 문제를 강사가 직접 만들어 보인다.

### 가네 9사태 — 묶음 하나의 미시 구조
주의 획득(비유나 시험 장면) → 목표 제시("이 묶음 끝나면 ○○과 △△을 한 문장으로 가릅니다") → 선수학습 회상(지도에서 지금 칸)
→ 자극 제시(구조도가 펼쳐짐) → 학습 안내(비유 대응, 묶음 기억법) → 수행 유도(강사가 질문하고 바로 함께 답함)
→ 피드백("여기서 많이들 ○○라고 쓰는데요") → 수행 평가(기출 판단) → 파지·전이(비유로 회수, 다음 칸으로).

### ARCS — 한 달 남은 수험생의 동기
- **A 주의**: 강마다 다른 비유, 묶음마다 첫 3초 안에 질문 하나.
- **R 관련성**: "이 단어가 지문에 보이면 답은 이쪽" 식으로 시험 장면과 바로 연결.
- **C 자신감**: 헷갈리는 짝을 갈라 주는 기준을 하나씩만 준다. 많아 보이는 목록도 묶음으로 줄인다.
- **S 만족감**: 지도가 한 칸씩 채워지는 게 눈에 보인다. 강 마지막에 완성된 한 장.

## 3. 이론 압축 4시간

전체 지도: **기술인 한 명을 길러 내는 다섯 질문**

| 질문 | 이론 강 | 공식 영역 |
|---|---|---|
| 왜 기르나 | 1강 앞부분 | 공업교육 일반 |
| 무엇을 가르치나 | 1강 뒷부분 | 공업 교육과정 |
| 어떻게 가르치나 | 2강, 3강 | 공업 교수학습, 실기지도법 |
| 잘 배웠나 | 4강 | 공업교육 평가 |
| 현장과 어떻게 잇나 | 4강 | 산학협력, 직업 진로 지도 |

### 이론 1강 · 왜 기르고, 무엇을 가르치나 (60분)
- **핵심 비유**: 레시피를 외운 사람과 셰프. 레시피대로는 누구나 만든다. 재료가 바뀌었을 때 판단하는 사람이 셰프다.
  셰프를 키우려면 레시피북이 필요하고, 좋은 레시피북은 잘하는 셰프들의 실제 일에서 뽑아낸다.
- **왜 기르나 (15분)**: 공업교육의 정의(공업 분야·입직 준비와 입직 후 향상·지식·기능·태도), 직업준비교육과 계속교육,
  교육과 훈련(데일 8축을 세 묶음으로, 시행상 4축), 지식의 두 축(용도 × 유형, 실천과학),
  기술이 전해져 온 길(도제 → 기계연구소 → 러시안 시스템 → 수기훈련 → 스미스-휴즈법 → 오늘의 학교 유형), 장학의 종류
- **무엇을 가르치나 (45분)**: 광역형과 협역형, 2022 개정 직업계고 편제(보통 64·전문 80·자율 30·창체 18, 192학점, 1학점 = 50분 16회)와
  2015 개정과의 차이, 전문 공통·전공 일반·전공 실무, NCS(정의·법적 근거·분류·능력단위 구조·직업기초능력),
  NCS ↔ 학습모듈 ↔ 교육과정 대응, 직무분석(최초분석·비교확인·DACUM), DACUM의 세 가정·참가자·절차,
  작업분석과 직업능력 프로파일, 직업군 분석, 캠벨 모형, 능력중심교육

### 이론 2강 · 어떻게 가르치나 I — 수업을 설계하는 법 (60분)
- **핵심 비유**: 내비게이션. 목적지(목표) → 현재 위치(출발점 진단) → 경로 안내(수업) → 도착 확인(평가) → 재탐색(피드백).
- **지식 구조**: 행동·인지·구성주의, Tyler 학습경험 선정·조직 원리, 목표 분류(Bloom 인지·정의·심동, Mager 5능력),
  목표 진술(Tyler·Mager·Gronlund), Glaser·KEDI, Dick & Carey, ADDIE, Gagné 9사태, ARCS, Carroll·완전학습,
  Ausubel, Bruner, Suchman, 매체(Dale·Bruner, ASSURE), 교육과정 평가(CIPP)

### 이론 3강 · 어떻게 가르치나 II — 실습실에서 일어나는 일 (60분)
- **핵심 비유**: 운전 연수. 강사 시범 운전 → 조수석에서 생각을 말로 들려주기 → 주차만 따로 연습 → 혼자 주행. 사고는 우연이 아니라 도미노.
- **지식 구조**: PBL, 프로젝트(킬패트릭), 협동학습(직소 I·II·III, STAD, TGT, Co-op Co-op), 토의 유형, 인지적 도제, 모듈,
  시범 원칙, Fitts 3단계, 연습(전습·분습 세 가지), 4단계 교수법, KEDI 개별확인식, 직접교수, 실습지시서,
  실습장 유형과 관리, 안전(하인리히·버드, 예방 4원칙, 대책 5단계)

### 이론 4강 · 잘 배웠나, 그리고 현장으로 (60분)
- **핵심 비유**: 체중계와 운전면허. 다른 걸 재면 타당도가, 잴 때마다 다르면 신뢰도가 무너진다. 등수가 아니라 합격선으로 보는 게 성취평가제.
- **지식 구조**: 평가 기준·목적·시기, 평가도구의 질, 문항 제작, 성취평가제, 실기평가 영역, 수행평가 방법,
  체크리스트·평정척도·루브릭, 평정 오류, 자격제도, 산학협동의 목적·가치·5원리, 현장실습 유형과 절차,
  진로지도 3영역·5활동, Parsons·Roe·Holland·Ginzberg·Super·Tiedeman과 O'Hara
- **마무리 10분**: 다섯 질문 지도를 처음부터 끝까지 한 번에 다시 걷는다.

## 4. 기출 패턴 문풀 4시간

이론 강과 같은 칸을 다룬다(기출 1강 ↔ 이론 1강 …). 강 하나의 흐름:

| 구간 | 시간 | 하는 일 |
|---|---|---|
| 지도 다시 세우기 | 5분 | 이론 강의 마지막 한 장이 빠르게 다시 조립된다. 강사가 가지마다 "여기 뭐가 달려 있었죠? 네, ○○" 식으로 속도감 있게 되짚는다 |
| 출제 패턴 해부 | 7분 | 이 칸의 기출이 묻는 방식(명칭 빈칸형, 사례 판별형, 오류 수정형, 절차 배열형, 비교 서술형, 판본 대조형)과 각 유형에서 답이 정해지는 원리 |
| 고속 문풀 | 40분 | 같은 원리로 풀리는 문제를 묶어서 공업 기출 → 타교과 인접 기출 순으로 연타. 첫 문제만 길게, 뒤로 갈수록 결정 단서 한 줄로 |
| 신유형·예상 | 8분 | 2022 개정에서 바뀐 지점, 아직 안 나왔지만 같은 원리로 나올 수 있는 문제를 강사가 직접 만들어 풀어 보인다 |

- **타교과 인접 기출을 쓰는 이유**: 농업·수산·상업정보 등 다른 전문교과의 교과교육학 문제는 공업교육론과 같은 이론을 다른 소재로 묻는다.
  소재만 바꾼 같은 원리를 여러 번 만나야 처음 보는 지문에서도 원리가 보인다.
- **해설지와 겹치지 않게**: 정답 문장을 읽어 주지 않는다. "이 지문에서 답을 정한 단어는 무엇이고, 왜 다른 후보는 탈락하는가"만 다룬다.
- **기출 데이터**: 인계 자료의 기출 320문항(공업 69 + 타교과 251)을 개념별로 묶어 쓴다. (자료 수령 후 문항 배정 확정)

## 6. 모션 그래픽 시스템

참고 프롬프트 두 개(워드마크 마침표 안의 연속 테이크, 하이엔드 미니멀 릴)를 그대로 쓰지 않고, **강의에 필요한 원리만** 가져왔다.

| 참고 프롬프트의 원리 | 강의 영상에서의 변형 |
|---|---|
| 워드마크의 마침표 안에서 영상 전체가 펼쳐진다 | `공업교육론.` 의 마침표가 아이리스처럼 열리며 강의가 시작되고, 강이 끝나면 다시 마침표로 닫힌다. 마지막 프레임 = 첫 프레임 |
| 컷 없음, 모든 장면은 이전 장면에서 자란다 | 정교화 이론의 줌인·줌아웃을 그대로 화면 문법으로. 지도의 노드가 커져 장면이 되고, 장면이 접혀 다음 장면의 틀이 된다 |
| 하나의 요소가 비트 테이블로 모든 상태를 거친다 | 장면의 주 패널 하나가 위치·크기·모서리·색을 바꾸며 다음 장면으로 모프된다. 상태는 큐 테이블 하나로 관리 |

| 모든 모프는 cubic-bezier(.45,0,.15,1), 0.8초 | 그대로 적용. 스프링·바운스 없음 |

## 7. 제작 파이프라인

MP4를 렌더하지 않는다. 브라우저가 음성의 재생 시각 t 하나로 화면 전체를 계산해 그리므로, 대본·음성이 바뀌면 빌드(수 초)만 다시 하면 된다.

1. 대본은 `lecture/src/content/` 에 장면 단위 데이터로 쓴다. 발화 안에 `{큐}` 표시를 넣어 화면 이벤트를 단어에 묶는다.
2. `npm run voice` — 장면별로 ElevenLabs `with-timestamps` 호출 → 오디오 + 글자별 시각 → 큐 타임라인.
3. `npm run qa:voice` — 생성 음성을 다시 받아쓰기해 대본과 비교, 발음이 틀어진 장면만 재생성.
4. `npm run sfx` · `npm run mix` — 효과음(피크를 이벤트에 정렬)과 배경음(덕킹)을 섞어 -14 LUFS 마스터.
5. `npm run build` — HTML 플레이어와 묶음별 오디오(`dist/t01`).
6. `npm run still` — 플레이어 화면을 지정 시각에 캡처해 검수.
