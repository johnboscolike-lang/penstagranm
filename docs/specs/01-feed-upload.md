# 상세 명세서 01: 피드와 네 컷 업로드

## 목적

수업 기록을 항상 같은 구조로 남기기 위해 게시글 업로드를 4개의 고정 사진 슬롯으로 제한한다.

## 화면 구성

- 상단 히어로: 서비스 설명과 핵심 수치 표시
- 게시글 작성 패널
- 게시글 목록
- 우측 가이드 패널

## 입력 규칙

- `수업 제목`: 필수
- `캡션`: 필수
- `수업준비사진(자신이나오게)`: 필수
- `수업목표사진`: 필수
- `필기사진`: 필수
- `과제사진`: 필수

## 데이터 규칙

- `Post` 1건당 `PostPhoto` 4건
- `PostPhoto.slot`은 `PREP | GOAL | NOTES | ASSIGNMENT`
- 업로드 파일은 `public/uploads`에 저장하고 DB에는 상대 URL을 보관

## 예외 처리

- 사진이 4장 미만이면 업로드 거부
- 서버 저장 실패 시 오류 문구 반환
- 잘못된 HTTP 메서드는 405 반환
