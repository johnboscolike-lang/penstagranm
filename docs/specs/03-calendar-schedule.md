# 상세 명세서 03: 달력 일정 관리

## 목적

날짜 중심으로 수업 준비와 후속 작업을 기록한다.

## 구성

- 월간 그리드 42칸 고정
- 이전 달 / 다음 달 이동 버튼
- 선택 날짜 상세 패널
- 일정 등록 폼

## 데이터 필드

- `title`: 일정 제목
- `notes`: 메모
- `scheduledFor`: ISO datetime

## 인터랙션

- 날짜 셀 클릭 시 해당 날짜가 선택 상태가 된다.
- 선택 날짜의 일정 목록이 우측 패널에 표시된다.
- 일정 저장 후 같은 페이지를 새로 로드해 최신 상태를 반영한다.
