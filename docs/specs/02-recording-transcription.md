# 상세 명세서 02: 녹음 및 한국어 전사

## 목적

사진 기록만으로 담기 어려운 수업 설명을 음성과 텍스트로 함께 남긴다.

## 동작 방식

- 브라우저의 `MediaRecorder`로 오디오를 녹음한다.
- `SpeechRecognition` 또는 `webkitSpeechRecognition`으로 한국어 전사를 시도한다.
- 전사 중간 결과는 textarea에 반영되고, 확정 문장은 누적 저장된다.

## 사용자 흐름

1. 사용자가 `녹음 시작` 클릭
2. 마이크 권한 승인
3. 오디오와 한국어 전사 동시 시작
4. 사용자가 `녹음 종료` 클릭
5. 오디오 미리듣기와 전사 텍스트 유지

## 제약

- 브라우저 지원 여부에 따라 기능 차이가 있다.
- 미지원 브라우저에서는 수동 텍스트 입력으로 대체한다.

## 저장 정책

- 텍스트 전사 결과는 `Post.transcript`에 저장한다.
- 오디오 파일은 현재 버전에서 DB에 저장하지 않고 브라우저 미리듣기만 제공한다.
