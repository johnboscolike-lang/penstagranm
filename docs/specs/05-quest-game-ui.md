# 상세 명세서 05: 우리반퀘스트 게임 UI

pen스타그램의 네 컷 기록·댓글·전사·달력을 **아기자기한 도트 RPG 세계**로 묶은 화면 명세다.
기획 원문은 "우리반퀘스트 통합 기획"(학교 / 주간도전 / 내공간 3공간, 매주 새 출발, 누적 성장)을 따른다.

## 화면 구성 (3공간 + 하위 화면)

| 공간 | 경로 | 핵심 |
|---|---|---|
| 학교 | `/` | 오늘의 학교(다음 수업·급식·공지·일정). 점수·잠금 없이 바로 확인 |
| 학교 › 달력 | `/calendar` | 날짜 선택과 일정 등록을 한 페이지에서 처리 |
| 주간도전 | `/challenge` | 오늘 약속 3칸, 이번 주 팀·개인 순위, 참여 보상 진행 |
| 주간도전 › 기록 | `/record` | 준비·목표·필기·과제 **네 컷 4칸 모두 필수** + 한국어 전사 |
| 내공간 | `/myroom` | 내 정보, 지난주 성장 소식, 앞마당 꾸미기, 네 컷 성장 기록·댓글 |

- 모든 화면은 `GameShell`(장면 배경 + HUD + 하단 도크)을 쓴다.
- HUD 오른쪽 **간단히 보기** 버튼은 장면을 끄고 같은 기능을 목록으로만 보여 준다(선택은 `localStorage`, 접근 불가 시 메모리 폴백).
- 학교 정보(시간표·급식·공지)는 데모 데이터이며 화면에 출처와 확인 시각을 표시한다.

## 규칙 (모두 `src/utils/quest-rules.ts`, 테스트 있음)

- 약속 진행률 `f` = 확인한 서로 다른 단위 수 / 계획 단위 수 (0~1, 계획은 1 이상)
- 일간 점수 = `100 × (f1+f2+f3) / 3`, 약속 하나라도 `f = 1`이면 참여 도장 1개
- XP: 약속 칸당 `floor(20 × f)` + 하루 회고 10 → 하루 최대 70. 코인: 칸당 `floor(4 × f)` + 회고 2 → 최대 14
- 레벨 = `1 + floor(누적 XP / 100)`. 코인을 써도 XP·레벨은 줄지 않는다
- 주간 점수 = 대상 수업일(월~금, 오늘까지)의 일간 점수 평균. 지난 미수행일은 0점, 미래 날짜는 미포함
- 대상일 3일 미만은 "기록 모으는 중", 3일 이상은 "잠정", 주가 끝나면 "확정"
- 동점은 공동 순위(1, 1, 3 …). 기본 화면은 상위 3위 묶음 + 내 순위 + 지난주 대비 변화
- 팀 점수 = 팀원 대상일 점수 합 / 팀 전체 대상 학생일 수 (인원이 달라도 평균으로 비교)
- 주간 보상권: 서로 다른 3일(짧은 주는 대상일 수)에 도장을 받으면 1장. 순위와 무관, 모든 경로 합쳐 주 1장
- 배지 우선순위: 폭풍성장(기준선 +20점·도장 3개) › 다시 시작 › 첫걸음 › 꾸준한 도전
- 월요일 00:00(Asia/Seoul)에 주간 점수·순위·도장이 새로 시작하고 XP·레벨·코인·집·진도는 남는다

## 데이터 (Prisma + SQLite)

`Team`, `Student`(`isMe`가 데모 플레이어), `DailyPromise`(학생·날짜·칸 3개), `PromiseUnit`(쪽/단어 1칸, `promiseId + unitNo` 유일), `Purchase`(학생·아이템 유일). 기존 `Post`에는 `studentId`를 더했다.

- 같은 칸을 여러 번 눌러도 유일 키 때문에 한 번만 센다(재시도·중복 요청 안전).
- 오늘 약속만 고칠 수 있다. 지난 날의 약속은 잠긴다.
- XP·코인은 저장하지 않고 약속 기록과 게시글(하루 회고)에서 계산한다. 구매만 `Purchase`에 남긴다.

## API

- `POST /api/promise-units` `{ promiseId, unitNo, done }` → 확인된 칸 목록
- `POST /api/shop` `{ itemKey }` → 남은 코인 (`409` 이미 보유/코인 부족)
- `GET /api/sprites/[name].svg` 서버가 그려 주는 도트 배경·소품·프레임 (불변 캐시)
- 기존 `POST /api/posts`, `/api/comments`, `/api/schedule`은 그대로다.

## 도트 아트 파이프라인

- 글꼴: 갈무리(Galmuri11, OFL) 자체 호스팅 `public/fonts`
- 작은 스프라이트(캐릭터·아이콘)는 ASCII 격자 → 인라인 SVG (`PixelSprite`)
- 건물·나무·소품은 `src/utils/art`의 `PixelCanvas`로 절차 생성 → `/api/sprites`에서 SVG로 제공
- 패널·버튼은 12×12 도트 프레임을 `border-image`로 늘려 모서리가 깨지지 않는다
- 스프라이트 크기표(`manifest.ts`)는 `src/tests/sprites.test.ts`가 생성 결과와 대조한다

## 접근성·움직임

- 상태는 색뿐 아니라 글자·아이콘을 함께 쓴다 (도장, 확정/잠정 태그 등)
- `prefers-reduced-motion`에서는 모든 애니메이션을 사실상 끈다
- 장면 이미지는 모두 `aria-hidden`, 진행 막대는 `role="progressbar"`
