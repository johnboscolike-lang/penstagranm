# pen스타그램 PRD

## 1. 제품 개요

pen스타그램은 교사가 수업 장면을 인스타그램처럼 기록하되, 게시글 하나가 항상 4개의 고정 사진 슬롯으로 구성되는 교실 전용 기록 서비스다. 각 게시글은 `수업준비사진(자신이나오게)`, `수업목표사진`, `필기사진`, `과제사진`을 한 번에 올려야 하며, 댓글과 수업 녹음 전사, 달력 일정 기능이 함께 제공된다.

## 2. 목표

- 수업 기록을 빠르게 표준화한다.
- 학생 또는 동료 교사가 댓글로 반응을 남길 수 있게 한다.
- 수업 설명을 녹음하고 한국어 텍스트로 남긴다.
- 날짜별 수업 일정과 메모를 달력에서 관리한다.

## 3. 핵심 사용자

- 교사: 수업 아카이빙과 일정 관리의 주 사용자
- 학생: 댓글로 피드백을 남기는 보조 사용자

## 4. 핵심 사용자 시나리오

1. 교사는 피드 페이지에서 수업 제목과 캡션을 입력한다.
2. 4개의 고정 프레임에 각 사진을 하나씩 업로드한다.
3. 브라우저에서 녹음을 시작하고 수업 설명을 한국어로 전사한다.
4. 게시글을 업로드하면 피드 상단에 새 게시글이 나타난다.
5. 학생은 댓글을 남긴다.
6. 교사는 달력 페이지에서 날짜를 선택하고 일정과 메모를 추가한다.

## 5. 기능 요구사항

### 피드/업로드

- 게시글은 정확히 4개의 사진이 모두 채워져야 업로드 가능하다.
- 각 사진 슬롯의 라벨은 고정이다.
- 피드 카드에서는 네 컷이 한 번에 보인다.

### 댓글

- 게시글마다 댓글 작성이 가능해야 한다.
- 댓글은 이름과 본문을 입력받는다.

### 녹음/전사

- 브라우저에서 오디오 녹음 시작/종료가 가능해야 한다.
- 지원 브라우저에서는 한국어 전사가 텍스트 영역에 자동 누적되어야 한다.
- 미지원 브라우저에서는 안내 문구와 수동 편집 경로를 제공해야 한다.

### 일정 캘린더

- 월간 달력 레이아웃을 제공한다.
- 날짜별로 여러 일정과 메모를 기록할 수 있어야 한다.
- 선택한 날짜의 상세 일정이 우측 패널에 표시되어야 한다.

## 6. 비기능 요구사항

- 로컬 실행이 쉬워야 한다.
- SQLite 기반으로 즉시 데모 가능해야 한다.
- 모든 사용자 정의 함수에 JSDoc을 붙인다.
- 직접적인 `console.log` 사용 없이 logger를 사용한다.
- 테스트 코드를 포함한다.

## 7. 성공 기준

- `npm run dev`, `npm run build`, `npm run test`가 동작한다.
- 시드 데이터로 피드와 캘린더가 즉시 보인다.
- 새 게시글, 댓글, 일정이 각각 저장된다.
